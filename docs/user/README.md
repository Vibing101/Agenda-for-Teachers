# Οδηγίες χρήσης

Τα κείμενα αυτού του φακέλου απευθύνονται στον **εκπαιδευτικό που χρησιμοποιεί
την εφαρμογή**, όχι σε προγραμματιστή, και είναι στα ελληνικά. Ό,τι άλλο υπάρχει
στο `docs/` είναι τεχνικό και στα αγγλικά.

Αφορούν την **έκδοση 1.0.0** (στο πλαίσιο *Πού αποθηκεύονται τα δεδομένα*:
**Έκδοση εφαρμογής 1.0.0**, **Έκδοση σχήματος 10**).

| Κείμενο | Τι καλύπτει |
|---|---|
| [Αναλυτικός οδηγός εγκατάστασης](installation.md) | Βήμα προς βήμα, με **χωριστό μέρος για macOS και για Windows**: πού να βάλετε την εφαρμογή, το πρώτο άνοιγμα και τα παράθυρα ασφαλείας, οι ρυθμίσεις συγχρονισμού, η ενημέρωση, η απεγκατάσταση, και τι να κάνετε σε κάθε πρόβλημα. |
| [Οδηγός εγκατάστασης και δεδομένων](getting-started.md) | Η σύντομη εκδοχή: τι παραλαμβάνετε, η λίστα ελέγχου για το πρώτο άνοιγμα σε Mac και σε Windows, πού αποθηκεύονται τα δεδομένα σας, τα αντίγραφα ασφαλείας, ο κανόνας της μίας συσκευής, και τι κάνετε όταν δείτε «Το αρχείο δεδομένων άλλαξε στον δίσκο». |
| [Επαναφορά από αντίγραφο ασφαλείας](restore.md) | Βήμα βήμα, πώς γυρίζετε τα δεδομένα σας σε ένα παλιότερο αντίγραφο, χωρίς να σβήσετε τίποτα. |
| [Ροή εργασίας](workflow.md) | Πότε ανοίγετε τι: η καθημερινή, η εβδομαδιαία και η μηνιαία ροή, τι γίνεται στο τέλος κάθε περιόδου, και τι τυπώνεται από πού. |
| [Αναλυτικός οδηγός χρήσης](user-guide.md) | **Ενότητα προς ενότητα, οθόνη προς οθόνη**: τι γράφετε σε κάθε πεδίο, τι συμπληρώνεται μόνο του, τι συνδέεται με τι, και τι εξάγεται σε PDF. |

## Από πού να ξεκινήσετε

1. **Πρώτη φορά στον υπολογιστή σας**: η λίστα ελέγχου του
   [Οδηγού εγκατάστασης και δεδομένων](getting-started.md), και ο
   [Αναλυτικός οδηγός εγκατάστασης](installation.md) όταν κάτι δεν πάει όπως
   περιγράφεται.
2. **Πρώτη φορά μέσα στην εφαρμογή**: [Ροή εργασίας](workflow.md), ενότητα
   *Μία φορά, στην αρχή της χρονιάς*.
3. **Όταν κολλήσετε σε μια οθόνη**: [Αναλυτικός οδηγός χρήσης](user-guide.md),
   στην ενότητα που σας απασχολεί.
4. **Όταν θέλετε να γυρίσετε πίσω**: [Επαναφορά από αντίγραφο
   ασφαλείας](restore.md).

Η **Ροή εργασίας** και ο **Αναλυτικός οδηγός χρήσης** έχουν στο τέλος τους
ενότητα με ό,τι η εφαρμογή δεν κάνει, ώστε να μη χάνετε χρόνο ψάχνοντάς το.
