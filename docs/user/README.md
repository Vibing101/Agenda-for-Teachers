# Οδηγίες χρήσης

Τα κείμενα αυτού του φακέλου απευθύνονται στον **εκπαιδευτικό που χρησιμοποιεί
την εφαρμογή**, όχι σε προγραμματιστή, και είναι στα ελληνικά. Ό,τι άλλο υπάρχει
στο `docs/` είναι τεχνικό και στα αγγλικά.

Αφορούν την **έκδοση 1.0.0** (στο πλαίσιο *Πού αποθηκεύονται τα δεδομένα*:
**Έκδοση εφαρμογής 1.0.0**, **Έκδοση σχήματος 10**).

| Κείμενο | Τι καλύπτει |
|---|---|
| [Οδηγός εγκατάστασης και δεδομένων](getting-started.md) | Τι παραλαμβάνετε, πού να βάλετε την εφαρμογή, η λίστα ελέγχου για το πρώτο άνοιγμα σε Mac και σε Windows, πού αποθηκεύονται τα δεδομένα σας, τα αντίγραφα ασφαλείας, ο κανόνας της μίας συσκευής, και τι κάνετε όταν δείτε «Το αρχείο δεδομένων άλλαξε στον δίσκο». |
| [Επαναφορά από αντίγραφο ασφαλείας](restore.md) | Βήμα βήμα, πώς γυρίζετε τα δεδομένα σας σε ένα παλιότερο αντίγραφο, χωρίς να σβήσετε τίποτα. |
| [Ροή εργασίας](workflow.md) | Πότε ανοίγετε τι: η καθημερινή, η εβδομαδιαία και η μηνιαία ροή, τι γίνεται στο τέλος κάθε περιόδου, και τι τυπώνεται από πού. |

Δεν υπάρχει οδηγός κουμπί προς κουμπί για κάθε οθόνη. Η **Ροή εργασίας** δείχνει
πού βρίσκεται το καθετί, και ο πίνακας «Θέλω να…» στο τέλος της είναι ο πιο
γρήγορος δρόμος. Στο τέλος της υπάρχει και η ενότητα **«Τι δεν κάνει η
εφαρμογή»**, για να μη χάνετε χρόνο ψάχνοντας κάτι που δεν υπάρχει.
