# Οδηγίες χρήσης

Τα κείμενα αυτού του φακέλου απευθύνονται στον **εκπαιδευτικό που χρησιμοποιεί
την εφαρμογή**, όχι σε προγραμματιστή, και είναι στα ελληνικά. Ό,τι άλλο υπάρχει
στο `docs/` είναι τεχνικό και στα αγγλικά.

| Κείμενο | Τι καλύπτει |
|---|---|
| [Οδηγός εγκατάστασης και δεδομένων](getting-started.md) | Πού να βάλετε την εφαρμογή, το πρώτο άνοιγμα σε Windows και macOS, πού αποθηκεύονται τα δεδομένα σας, αντίγραφα ασφαλείας, και τι σημαίνουν τα μηνύματα που μπορεί να συναντήσετε. |
| [Ροή εργασίας](workflow.md) | Πότε ανοίγετε τι: η καθημερινή, η εβδομαδιαία και η μηνιαία ροή, και τι γίνεται στο τέλος κάθε περιόδου. |

## Τι λείπει ακόμη

**Ο αναλυτικός οδηγός ανά οθόνη** γράφεται όταν ολοκληρωθούν όλες οι ενότητες
της εφαρμογής. Μέχρι τότε η διάταξη των οθονών αλλάζει, και ένας οδηγός που
δείχνει κουμπιά που μετακινούνται είναι χειρότερος από καθόλου οδηγός.

Και τα δύο παραπάνω κείμενα έχουν στο τέλος τους ενότητα **«Τι δεν υπάρχει
ακόμη»**, ώστε να μη χάνετε χρόνο ψάχνοντας κάτι που δεν έχει φτιαχτεί.
