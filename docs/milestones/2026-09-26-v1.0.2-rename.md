# v1.0.2 — Ημερολόγιο Εκπαιδευτικού

**Date:** 2026-09-26
**Branch:** `docs-remove-source-rename`
**Signed off by:** the product owner chose the name and asked for this release, 2026-09-26

## What shipped

- **The app is renamed «Ημερολόγιο Εκπαιδευτικού»** (English: *Teacher Planner*). The new name appears in:
  - the window title and both interface languages
  - the footer of every printed PDF
  - the app's metadata (copyright, description)
  - CI's test-folder names
  - every doc and the suggested folder name in the Greek guides
- **The *Ατζέντα* notes section keeps its name**, because there the word just means "agenda".
- **The docs no longer refer to the original paper product**, its files, its page numbers or the local reference folder. The spec is now `docs/SPEC.md`. Decisions that cited a source page now give their own reasons. Each archived release note says so in its header.
- The version is `1.0.2` in `package.json`, `Cargo.toml` and `tauri.conf.json`, and the Greek guides say `1.0.2` / `11`.

## Decisions taken

| Decision | Call taken | Why |
|---|---|---|
| The new name | **Ημερολόγιο Εκπαιδευτικού** | The product owner's choice |
| The English name | **Teacher Planner**, which the file names already used. It replaces "Teacher's Agenda" | That was a translation of the old name |
| The bundle identifier `gr.atzenta.teacher-planner` | **Unchanged** | No user sees it. Changing it would make macOS treat the update as a different app, with fresh Gatekeeper prompts |
| The teacher's existing folder | **Keeps whatever name it has** | The app reads its data from beside itself, whatever the folder is called. The guides say how to rename it safely |
| Scope of the text cleanup | **Docs only** | The product owner's choice. Code and test comments still refer to the original material |
| History | **Unchanged** | The product owner's choice. Past commits, the `v1.0.0`/`v1.0.1` tags and their releases keep the old name |
